# MEB COP31 OGM Reel'leri — onay sayfası

Statik sayfa (GitHub Pages). Yanıtlar `apps-script/Code.gs` ile Google E-Tablo'ya yazılır ve sayfada herkese gösterilir.

- `index.html` içindeki `ONAY_SCRIPT_URL`: Apps Script web uygulaması adresi.
- Paftalar: `paftalar/pafta-N.jpg`. Sayfa, `scripts/ogm2-onay-site.mjs` ile üretilir (COP31_ODSGM projesi).
